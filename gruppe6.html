Snakk med datamaskina!

PowerShell er eit program der du skriv kommandoar i staden for å klikke med musa. Du seier kva datamaskina skal gjere, og ho gjer det.

💡

Kva er PowerShell?

Eit verktøy frå Microsoft som styrer Windows med tekst. Det er også eit skriptspråk: du kan skrive fleire kommandoar i ei fil og køyre dei på nytt kva gong du vil.

🛠️

Kva brukar ein det til?

Å finne filer, lage mapper, sjå kva som køyrer på maskina, og å gjere kjedelege oppgåver automatisk. IT-folk brukar det kvar dag for å styre mange maskinar samtidig.

🚀

Kvifor lære det?

Du lærer å tenke som ein programmerar, og du blir raskare på datamaskina. Det er ein flott start om du vil jobbe med IT.
